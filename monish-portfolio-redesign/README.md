# Monish V. — Portfolio

An immersive monochrome React portfolio built with Vite and Framer Motion. The experience uses a cinematic hero, animated typography and counters, a moving skills ticker, engineering-principle stories, filterable project case studies, a visual skills section, a research and achievement timeline, responsive navigation and a desktop-only custom cursor.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Included assets

- `public/resume.pdf` — current resume
- `public/certificates/icngsmca-2026.pdf` — conference participation certificate
- `public/projects/` — four project screenshots used in the featured project section

## Update links and content

Edit project URLs, contact/social links, project descriptions and skills in `src/main.jsx`. Keep the image filenames in sync with the `image` values in the featured project data.
